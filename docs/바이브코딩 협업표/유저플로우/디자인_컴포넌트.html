STEP 1

시작 뼈대 복사

맨 아래 시작 뼈대를 복사해 새 HTML 파일을 만듭니다. 공통 CSS와 FlowKit이 이미 들어 있습니다.

STEP 2

컴포넌트 끼워 넣기

문서 섹션마다 맞는 컴포넌트의 코드 보기를 열어 복사하고, 중괄호 자리만 바꿉니다.

STEP 3

점검

05 다이어그램 (FlowKit) 형식서 5장 · 좌표 데이터만 쓰면 SVG로 그려짐

블록 6종 + 실선 · 빨간 점선 + 회색 메모 + (미정) 메모. 아래 코드는 이 그림의 데이터다. 블록 크기와 배치 간격은 형식서 5-1, 5-2.

FlowKit의 card 블록(누가 · 무엇을 · 링크)과 연결점 배지가 붙은 화살표. 카드를 누르면 해당 FlowCard로 이동한다.

위쪽 왼편: 플로우 배지 · 누가 · 무엇을 · 목표 · 화면 칩. 오른편: MemoList. 아래: FlowCanvas. 플로우마다 하나씩 쌓는다(space-y-8).

{무엇을}

목표 · {이 플로우가 끝나면 이뤄지는 것}

{화면 번호}

  • {메모}
  • (미정) {정할 것}

다이어그램 렌더러 전체 코드. 이 파일의 이 스크립트가 원본이다. 고칠 때는 여기를 고치고 형식서 5장도 함께 고친다.

FlowKit.mount(el, id, data)
el 안에 SVG를 그린다. id는 페이지 안에서 겹치지 않게.
FlowKit.render(id, data)
SVG 문자열만 돌려준다. 템플릿 문자열 안에 넣을 때.
FlowKit.check()
겹침 점검. 빈 배열이면 끝. 문제는 콘솔에 한국어로 나온다.
