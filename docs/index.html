새 문서를 넣을 때

  • 단계가 맞는 폴더에 넣고, 이 목차의 02 절에 카드 하나를 추가합니다.
  • 파일 이름은 문서명_쿠션톡_YYMMDD. 고친 날짜가 바뀌어도 이름은 처음 만든 날로 둡니다.
  • 안 쓰게 된 시안 · 문서는 지우지 말고 보관/으로 옮깁니다.
  • 문서 안의 "근거" 줄에 적힌 이름은 글자일 뿐이라, 파일을 옮겨도 깨지는 링크는 없습니다.
