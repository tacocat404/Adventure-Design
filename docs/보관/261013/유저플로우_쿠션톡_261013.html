RULE 1교사 화면 첫 줄은 목적

감정은 배지로만. 공격 구절은 같은 폭 '표현 가림' 칩으로 바꿔요.

RULE 2긴급은 거르지 않는다

학교폭력·아동학대·안전은 원문 그대로 맨 위. 근무시간 밖에도 바로.

RULE 3애매하면 위협

놓치는 것보다 헛경보가 나아요. 위협은 교사 대신 관리자에게.

RULE 4원문은 지우지 않는다

교사는 한 번 더 확인 후 열람, 관리자는 시각·지문과 함께 보존.
