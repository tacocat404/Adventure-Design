# 쿠션톡 설계 문서

쿠션톡을 만들면서 정한 내용을 단계별로 모았습니다. 앞 문서가 뒤 문서의 근거라서, 처음이면 위에서부터 읽으면 됩니다.

HTML 문서는 GitHub에서 글자로만 보입니다. 레포를 받은 뒤 [index.html](index.html)을 브라우저로 열면 모든 문서를 카드로 볼 수 있습니다.

| 2. 사용자 흐름 | [유저플로우](2_사용자흐름/유저플로우.md) ([흐름도](2_사용자흐름/유저플로우.html)) | 사용자별 흐름 7개와 흐름마다 정한 규칙 |
| | [와이어플로우](2_사용자흐름/와이어플로우.html) | 흐름 위에 화면을 얹어 화면 사이 연결을 본 것 |

## 폴더

```
docs/
├─ index.html          문서 목차 (브라우저용)
├─ 1_기획/
├─ 2_사용자흐름/
├─ 3_화면디자인/
│  └─ 추가시안/
├─ 4_시스템설계/
├─ 5_AI/
└─ images/             README 그림
```

코드와 문서는 이렇게 이어집니다: 화면은 와이어프레임 · 컴포넌트 명세(`frontend/`), 서버는 API 명세(`backend/app/api/`), DB는 DB 설계의 생성문(`backend/app/db/schema.sql`)을 따릅니다.
