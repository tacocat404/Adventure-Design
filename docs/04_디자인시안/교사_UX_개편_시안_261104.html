교사 화면 개편 시안

교사가 하루에 여는 화면을 하나(오늘)로 만들고, 공지·설문·반 톡방은 보내기로 분리해요. 둥근 카드 대신 납작한 목록, 이모지 대신 선 아이콘을 써요.

1. 지금 → 개편

같은 날 같은 데이터(긴급 1, 답장 2, 결석 2·조퇴 1, 체험학습 1)예요. 점선은 난잡한 곳이에요.

→

2. 오늘 화면의 상태 · 하위 화면

3. 보내기 · 설정

4. 이번에 바꾼 모양 규칙

모양

· 둥근 카드 → 흰 목록 + 가는 구분선
· 모서리는 3~8px (칩 3, 아이콘 타일 6, 버튼 8)
· 긴급만 왼쪽 빨간 선으로 강조

버튼

· 숫자 칸 → 아이콘 버튼 + 옆 숫자
· 승인 / 반려 → 꽉 찬 사각 하단 바
· 만들기 → ＋ 하나

아이콘

· 이모지 모두 제거
· 2px 선 아이콘 (탭바 · 시트 · 버튼 · 안내 줄)
· 쿠션이는 일반 화면에서만
