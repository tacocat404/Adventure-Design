# AI 판단 평가 결과

평가셋 `ml/eval_set.json` — 문장 60개(거친 30 · 괜찮은 30), 메시지 30개. 로컬 모델 `smilegate-ai/kor_unsmile` 켜짐.

⚠️ 키워드 사전과 평가셋을 같은 사람이 만들어 **키워드 점수는 실제보다 높게 나올 수 있다.** 팀원이 새 문장을 더하면 더 공정해진다.

## 3. 속도

- 로컬 판단: 문장 하나에 약 9ms (CPU)
- 분석 전체(판단 + API 요약): 평균 3.0초 · 최대 4.3초 (claude-haiku-5-5, 6건)
- 보내기 전 검사(판단 + API 제안 문장): 3.1초 — 5초 규칙 통과
